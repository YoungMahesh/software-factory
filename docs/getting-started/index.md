# Getting Started

Welcome to **Modal Sandboxes**. This guide will walk you through prerequisites, environment configuration, and launching your first sandbox.

## What is Modal Sandboxes?

Modal Sandboxes is a cloud execution toolkit built on top of [Modal](https://modal.com). It allows you to:
1. Spin up clean, disposable Linux development environments on demand.
2. Connect securely via SSH (`ssh <sandbox-name>`) or web tunnels (port 3000).
3. Test applications inside isolated Linux VMs with Docker-in-Docker support.
4. Run AI coding agents (T3 Code, OpenCode, Antigravity, Pi) inside managed environments.
5. Capture snapshots of sandbox states to pause and resume work instantly.

## Learning Path

1. **[Prerequisites & Setup](prerequisites.md)**: Ensure you have Python 3.11+, Git, and a configured Modal account.
2. **[Quickstart](quickstart.md)**: Launch a standalone sandbox in 60 seconds with zero additional configuration.
