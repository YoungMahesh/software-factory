# Getting Started

Software Factory supports three main workflows:

- Launch a disposable Modal development sandbox through the CLI or Hosted Sandbox Control Plane.
- Run a Resource Plane for persistent PostgreSQL databases and S3 buckets.
- Scaffold an application from `app-template/` and optionally deploy it to a VPS.

Start with [prerequisites](prerequisites.md) and the [sandbox quickstart](quickstart.md). For application work, continue to [application creation and deployment](../guides/applications.md). For persistence infrastructure, follow [Resource Plane deployment](../guides/resource-plane-deployment.md).

The [CLI reference](../guides/cli.md) lists supported commands and flags. [Architecture](../architecture/overview.md) explains how the three subsystems connect.
