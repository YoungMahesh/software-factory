# Architecture Decision Records (ADRs)

Architecture Decision Records (ADRs) document architectural and design choices made in the evolution of `modal-sandboxes` and `software-factory`. Each record outlines the context, considered options, decision outcome, and consequences.

## Overview

The repository documents decisions covering:

- **Unified Sandbox Runner & Runtimes**: Standard container and Linux VM environments with full Docker-in-Docker support.
- **Ingress & Networking**: Zero-config OpenSSH daemon access, SSH key management, and prebaked Cloudflare Tunnels on port 3000.
- **Secrets & Decryption**: Ephemeral in-sandbox credentials, SOPS encryption with Age keys (`share0`), and unified `.env` configuration.
- **AI Agent Tooling**: Native integration of T3 Code server, Antigravity CLI and Remote Control daemon, OpenCode server, and Pi Agent.
- **Control Plane & Snapshots**: Serverless web control plane, REST API, copy-on-write filesystem snapshotting, and snapshot restoration.
- **Code Standards & Architecture**: Single-context domain layout and the Universal File Line Budget (<= 500 lines).
