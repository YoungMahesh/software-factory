# Glossary

Canonical language for domain concepts in this project. Engineering skills (like `/domain-modeling`, `/grill-with-docs`, and `/to-tickets`) read this file to enforce consistent terms.

## Language

**App Workspace**:
The core user interface and web application (`apps/web`).

**Mobile Client**:
The React Native / Expo application (`apps/mobile`), sharing theme tokens and types with the web workspace.

**Design System Theme**:
The centralized tokens package (`@repo/theme`) providing colors, typography, radii, and Tailwind / NativeWind presets.
