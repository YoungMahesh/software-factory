# App Template

Canonical full-stack Next.js 16 + optional Expo React Native starter blueprint for Software Factory.

Use `create-app` (or `modal-sandbox create-app`) to scaffold a new project from this blueprint, optionally wiring GitHub repository creation, Resource Plane PostgreSQL (`create-db`), SeaweedFS S3 (`create-s3`), Central Environment Store (`push-repo-env`), and Modal Sandbox provisioning.

See [ADR 0087](../docs/adr/0087-app-template-and-scaffolder-integration.md) and the [CLI Guide](../docs/guides/cli.md).
