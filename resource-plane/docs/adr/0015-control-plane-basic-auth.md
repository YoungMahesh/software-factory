# Control Plane Basic Authentication

To prevent unauthorized access to the control plane dashboard and server functions when exposed on a local or remote network, the control plane enforces HTTP Basic Authentication (RFC 7617) via TanStack Start request middleware. Credentials reside strictly in the environment (`.env.local` or environment variables `BASIC_AUTH_USERNAME` and `BASIC_AUTH_PASSWORD`, defaulting the username to `admin`) with zero reliance on the system database or its settings table. If credentials are not present in `.env.local` on server launch, the Vite dev server startup hook automatically generates a cryptographically secure random password, appends the credentials to `.env.local`, and prints them immediately to the terminal stdout. All dashboard UI routes and server functions require authentication, while the `/mcp` endpoint is explicitly exempted because it is independently secured by the Bearer Admin Token.
