# Master Superuser and Storage Admin Credential Hardening

To eliminate network vulnerability vectors arising from default static credentials and wildcard interface bindings, the PostgreSQL container (port 5432) and SeaweedFS S3 gateway (port 8333) bind to localhost (`127.0.0.1`) by default, and legacy containers bound to `0.0.0.0` are automatically detected and recreated. Master Database Credentials (`POSTGRES_PASSWORD`) and Storage Admin Credentials (`SEAWEEDFS_ADMIN_ACCESS_KEY`, `SEAWEEDFS_ADMIN_SECRET_KEY`) are removed from hardcoded code paths; instead, cryptographically secure random credentials are generated on startup, persisted into `.env.local` if not already defined, and loaded via environment variables. For existing PostgreSQL volumes initialized with legacy credentials, the Auto-Bootstrapper detects authentication failure and transparently rotates the database user password to match the active configured credentials.
